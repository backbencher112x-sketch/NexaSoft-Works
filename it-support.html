1. Slow Laptop & Windows Hang FixStartup apps, temp junk & speed boost
▾

Step 1: Disable Heavy Startup Apps

  1. Press Ctrl + Shift + Esc to open Task Manager → go to Startup apps.
  2. Right-click heavy apps you don't need at boot (Spotify, Teams, Steam, OneDrive) and select Disable.

Step 2: Clean Temporary Junk Files

  1. Press Win + R, type %temp% and press Enter → select all (Ctrl + A) → Delete (skip files currently in use).
  2. Repeat with temp and enable Settings → System → Storage → Storage Sense.
Hardware Tip: If your laptop uses an old HDD and takes 2+ minutes to boot, upgrading to an SSD makes it 5x faster.
🌡️
2. Laptop Overheating & Loud Fan FixAirflow, CPU load & power plan control
▾

Step 1: Fix Airflow Immediately

  1. Never use a laptop directly on a bed, pillow, or blanket—it blocks bottom air vents and traps heat.
  2. Use a flat desk or slightly lift the back edge for airflow; gently clean dust from vents with dry air.

Step 2: Lower Background CPU Heat

  1. Open Task Manager → Processes and sort by CPU to close any stuck app using 50%+ CPU.
  2. Open Settings → System → Power & battery and switch Power mode to Balanced (instead of Best Performance) for everyday work.
🟦
3. Blue Screen (BSOD) & Corrupted System FixSafe Mode, SFC & DISM repair commands
▾

Step 1: Repair Corrupted Windows Files

  1. Click Start, type cmd, right-click Command Prompt → Run as administrator.
  2. Run: DISM /Online /Cleanup-Image /RestoreHealth and wait until 100%.
  3. Then run: sfc /scannow and restart your PC when done.

Step 2: Check Recent Drivers / Updates

  1. Note the stop code on the Blue Screen (e.g. MEMORY_MANAGEMENT or VIDEO_TDR_FAILURE).
  2. Update graphics/chipset drivers via Windows Update → Advanced options → Optional updates.

4. Laptop Wi-Fi Not Connecting / No InternetDNS flush, IP reset & Wi-Fi driver fix
▾

Step 1: Refresh Network via Command Prompt

  1. Open Command Prompt (Admin) and run these 3 commands one by one:
  2. ipconfig /flushdns
  3. netsh winsock reset & netsh int ip reset → then restart your PC.

Step 2: Built-In Windows Network Reset

  1. Go to Settings → Network & internet → Advanced network settings → Network reset → Reset now.
  2. If the Wi-Fi icon is completely missing, open Device Manager → Network adapters, right-click your Wi-Fi adapter → Enable (or Uninstall → Restart to auto-reinstall).

5. PC Sound, Mic or Bluetooth Not WorkingOutput device, privacy mic & audio restart
▾

Step 1: Check Output & Mic Permissions

  1. Click the Speaker icon on the taskbar → tap the arrow next to volume → select the right speakers/headphones.
  2. For Microphone: go to Settings → Privacy & security → Microphone and make sure Microphone access is ON.

Step 2: Restart Windows Audio Service

  1. Press Win + R, type services.msc → find Windows Audio → right-click → Restart.
🖨️
6. Printer Stuck or USB Pendrive Not ShowingPrint Spooler restart & Drive Letter fix
▾

Fix Stuck Printer Queue

  1. Press Win + R → type services.msc → right-click Print Spooler → Restart.
  2. Unplug the printer power cord for 30 seconds and reconnect.

Fix USB Drive Connected But Not Showing

  1. Right-click the Start button → Disk Management.
  2. Find your USB drive at the bottom → right-click it → Change Drive Letter and Paths → Add (pick any letter like E: or F:).

7. Remove Virus, Malware & Browser Pop-UpsWindows Defender Offline Scan & cleanup
▾

Step 1: Run Microsoft Defender Offline Scan (Free & Deep)

  1. Open Windows Security → Virus & threat protection → Scan options.
  2. Select Microsoft Defender Antivirus (offline scan) → click Scan now (PC restarts and removes deep rootkits safely).

Step 2: Clean Browser Hijackers

  1. In Chrome/Edge, remove unknown extensions (chrome://extensions) and reset spam site notifications.
  2. Uninstall suspicious programs under Settings → Apps → Installed apps.
