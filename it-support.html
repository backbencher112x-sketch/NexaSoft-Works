15 deep PC & Laptop guides — Windows speed, Wi-Fi, hardware, security & shortcuts.

🚀
1. Slow Laptop & Windows Hang FixStartup apps, temp junk & speed boost
▾

Disable Startup Apps

  1. Press Ctrl+Shift+Esc → Startup apps → right-click unused heavy apps (Spotify, Teams, Steam) → Disable.

Clean Junk Files

  1. Press Win+R, type %temp% → Ctrl+A → Delete (skip in-use files). Turn ON Storage Sense in Settings → Storage.
🌡️
2. Laptop Overheating & Loud Fan FixAirflow, CPU load & Balanced power
▾

Fix Airflow & CPU Heat

  1. Never keep a laptop on a bed or pillow (blocks air vents); use a flat desk and clean dust from vents.
  2. In Task Manager → CPU, close stuck apps using 50%+ CPU, and set Power mode to Balanced.
🟦
3. Blue Screen (BSOD) & System RepairDISM & SFC repair commands
▾

Repair Windows Files

  1. Open Command Prompt (Admin) and run: DISM /Online /Cleanup-Image /RestoreHealth.
  2. Then run sfc /scannow and restart your PC. Update drivers via Windows Update → Optional updates.
🔄
4. Windows Update Stuck or Failing FixTroubleshooter & update cache reset
▾

Reset Update Cache

  1. Run Settings → System → Troubleshoot → Other troubleshooters → Windows Update.
  2. Still stuck? In CMD (Admin) run net stop wuauserv & net stop bits, clear C:\Windows\SoftwareDistribution, then run net start wuauserv & net start bits.
📡
5. Laptop Wi-Fi Not Connecting / No NetDNS flush, IP reset & driver fix
▾

CMD & Network Reset

  1. In CMD (Admin) run: ipconfig /flushdns, netsh winsock reset, netsh int ip reset → Restart.
  2. Or use Settings → Network → Advanced network settings → Network reset. Check Device Manager → Network adapters if Wi-Fi icon is missing.
🎧
6. PC Sound, Mic or Bluetooth FixOutput device, mic access & service
▾

Audio & Mic Steps

  1. Click taskbar Speaker icon → pick the correct output device. Enable Mic under Settings → Privacy → Microphone.
  2. Press Win+R → services.msc → right-click Windows Audio → Restart.
🖨️
7. Printer Stuck or USB Not ShowingPrint Spooler & Drive Letter fix
▾

Quick Hardware Fix

  1. Printer: Open services.msc → right-click Print Spooler → Restart; unplug printer 30s.
  2. USB Pendrive: Right-click Start → Disk Management → right-click USB → Change Drive Letter → Add.
🖥️
8. Black Screen, Keyboard or Touchpad FixGPU reset shortcut & Fn lock check
▾

Instant Screen & Touchpad Reset

  1. Black/Frozen Screen: Press Win+Ctrl+Shift+B to restart the graphics driver instantly without losing work.
  2. Touchpad: Press your laptop's Fn + Touchpad key (F6/F7/F9) and verify ON under Settings → Bluetooth & devices → Touchpad.
🛡️
9. Remove Virus, Malware & Pop-UpsDefender Offline Scan & Chrome clean
▾

Deep Free Scan

  1. Open Windows Security → Virus & threat protection → Scan options → select Microsoft Defender Offline scan → Scan now.
  2. Remove unknown extensions at chrome://extensions and uninstall suspicious apps.
📦
10. Essential Free Software for New PCVLC, 7-Zip, LibreOffice, VS Code & Ninite
▾

Trusted Free Apps

  1. VLC (video), 7-Zip (ZIP/RAR), LibreOffice (free Word/Excel/PPT), VS Code (coding).
  2. Use ninite.com to install official apps in 1 click with zero adware.
🧩
11. Fix "Missing DLL" / App Won't OpenVisual C++ Redistributable & DirectX
▾

Official Runtime Fix

  1. Install official Microsoft Visual C++ Redistributable (x64 & x86) from microsoft.com (fixes vcruntime140.dll errors).
  2. For games, install DirectX End-User Runtime and try Run as administrator.
🔑
12. Forgot Windows PIN / Password FixLock-screen PIN reset & Microsoft recovery
▾

Safe Account Recovery

  1. Connect Wi-Fi on lock screen → click I forgot my PIN → verify via Microsoft OTP to set a new PIN.
  2. Or click Sign-in options to use your password, or reset online at account.live.com/password/reset.
⌨️
13. Top Windows Keyboard ShortcutsClipboard, Screenshot, Lock & Snap
▾

Must-Know Shortcuts

  1. Win+V Clipboard History | Win+Shift+S Screenshot Snip | Win+L Lock PC | Win+D Show Desktop.
  2. Ctrl+Shift+T Reopen closed browser tab | Win+Left/Right Split screen apps | Win+. Emojis.
🔋
14. Laptop Battery Health & Backup TipsOfficial Windows Battery Report
▾

Check Battery Health

  1. Run powercfg /batteryreport in Command Prompt and open the saved HTML report to check Design vs Full Charge Capacity.
  2. Enable 80% Charge Limit / Conservation Mode in Lenovo Vantage, MyASUS, or Dell Power Manager when plugged in daily.
💾
15. Free C: Drive Space SafelyDisk Cleanup & old installers cleanup
▾

Clean C: Drive (No Data Loss)

  1. Search Disk Cleanup → select C: → click Clean up system files → check Windows Update Cleanup, Temp files & Recycle Bin.
  2. Sort Downloads by Size and delete old .exe / .iso installers.
